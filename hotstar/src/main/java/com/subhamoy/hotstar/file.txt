if i have to select maven when i running spring boot application ,
 application  not working why

Normally, no—you can run a Spring Boot app using an Application configuration.
In your IntelliJ installation, the Application configuration fails before Spring Boot starts because IntelliJ’s internal build server throws:

BuiltInServerManagerImpl.createServerBootstrap
BuildManager.startListening
NullPointerException

That is an IntelliJ problem, not a Spring Boot or project problem.
Maven works because it starts the app through:

mvn spring-boot:run

Maven compiles and runs your project using pom.xml, bypassing IntelliJ’s broken Application build process.
